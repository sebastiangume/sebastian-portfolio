PUBLICACIÓN GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com si aún no tienes.
2. Pulsa el + (arriba a la derecha) > New repository.
3. Nombre recomendado: sebastian-portfolio
4. Selecciona Public y crea el repositorio.
5. Pulsa Add file > Upload files.
6. Sube index.html, style.css, script.js y cv.pdf.
7. Pulsa Commit changes.
8. En el repositorio, entra en Settings > Pages.
9. En Build and deployment, elige Deploy from a branch.
10. Selecciona Branch: main y folder: /(root), y pulsa Save.
11. GitHub Pages mostrará una dirección similar a:
    https://TU-USUARIO.github.io/sebastian-portfolio/

La dirección exacta depende de tu nombre de usuario de GitHub.
Para actualizar la web, sube los archivos modificados al mismo repositorio.
